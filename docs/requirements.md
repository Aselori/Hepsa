# Requerimientos y módulos

## Portal público

1. El usuario puede consultar el catálogo de productos activos.
2. El usuario puede agregar productos al carrito.
3. El usuario puede enviar solicitudes para proyectos a medida.
4. El usuario puede registrarse e iniciar sesión.
5. El sistema puede restaurar la sesión existente.
6. El usuario puede cerrar sesión.
7. El usuario puede consultar información de su perfil.

## Panel administrativo

1. El empleado autorizado puede acceder al panel.
2. El empleado puede registrar ventas mediante el POS.
3. El sistema calcula subtotal, IVA y total.
4. El sistema permite seleccionar el tipo de pago.
5. El sistema puede registrar la venta y sus artículos.
6. El sistema puede generar un ticket PDF.
7. El empleado puede consultar el historial de ventas.
8. El empleado puede crear, editar, activar, desactivar y eliminar productos.
9. El empleado puede gestionar inventario y existencias.
10. El empleado puede consultar y actualizar solicitudes de proyectos.
11. El empleado puede consultar perfiles de usuarios.
12. El empleado puede configurar el porcentaje de IVA y el mensaje del ticket.

## Datos

El código actual utiliza las entidades `products`, `custom_requests`, `orders`, `order_items` y `profiles`, además del bucket `product-images`.
